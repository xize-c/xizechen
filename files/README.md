# 个人主页 (Next.js App Router)

1. 新建项目：`npx create-next-app@latest my-site --typescript --app`（Tailwind 可选，本代码不依赖）
2. 把本目录的 `app/`、`components/`、`data/` 覆盖进去（tsconfig 默认已有 `@/*` 路径别名）
3. 在 `public/` 放入 `images/me.jpg`、`images/*.jpg`（缩略图）和 `cv.pdf`
4. 改 `data/content.ts` 的内容
5. `npm run dev`；部署推荐 Vercel
